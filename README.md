# Paisa – Personal Wealth Tracker 💰

A simple and interactive personal finance management website built using HTML, CSS and JavaScript.

### 🚀 Live Demo
https://wealth-tracker-three-iota.vercel.app

### ✨ Features
- Income and expense tracking
- Monthly budget management
- Savings goals tracking
- Interactive financial dashboard
- Spending analytics and charts
- Light and dark mode
- CSV export functionality

### 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Chart.js
- LocalStorage

### 📌 Project Overview
Paisa helps users manage their personal finances by tracking transactions, monitoring spending habits, setting budgets and achieving savings goals through an easy-to-use dashboard.
